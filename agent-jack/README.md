# Agent Jack onboarding

**Early adopter?** This is the public setup guide for [Agent Jack](https://agentjack.kraliki.com). Hand it to your coding agent (Codex, Claude Code, …) on your Mac:

> Read https://github.com/m-check1B/onboarding/blob/main/agent-jack/AGENTS.md and set up Agent Jack on my Mac, step by step. Ask me before every install.

Or clone it (`git clone https://github.com/m-check1B/onboarding.git ~/Developer/onboarding`), open its `agent-jack` folder in your agent and say the same.

Everything the agent needs is in [AGENTS.md](AGENTS.md): what your Mac needs, which access we gave you, each step with a check, and when it has to stop and let you do something yourself (sign-ins, 2FA, macOS prompts, anything that costs money). You sign in yourself; the agent never sees your passwords.

When something doesn't work, reply to the welcome e-mail with the report the agent prints at the end.

Related public repos: [agent-jack-setup](https://github.com/m-check1B/agent-jack-setup) (Local labs on your Mac: install, doctor, repair; AGENTS.md Part E runs it for you) and [t3-code-tentacles](https://github.com/m-check1B/t3-code-tentacles) (how Jack drives coding agents through T3 Code).

Česky: Dejte svému agentovi (Codex, Claude Code…) na Macu tento pokyn: „Přečti si https://github.com/m-check1B/onboarding/blob/main/agent-jack/AGENTS.md a nastav mi krok za krokem Agent Jacka na Macu. Před každou instalací se mě zeptej.“ Přihlašujete se vždy sami; agent vaše hesla nikdy nevidí.
